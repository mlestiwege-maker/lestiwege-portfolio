# Lestiwege.dev Portfolio

This is the personal portfolio for **Lestiwege Mufutumari** — a full-stack and mobile developer focused on building modern web, mobile, and software solutions.

The site is built with **React**, **TypeScript**, **Vite**, **Tailwind CSS**, and animation/icon libraries for a clean, modern presentation.

## Features

- Responsive single-page portfolio layout
- Animated hero section and scrolling sections
- Skills showcase with technology icons
- Project highlights
- Contact links for GitHub, email, and phone
- Dark, polished UI

## Tech stack

- React 19
- TypeScript
- Vite
- Tailwind CSS
- Framer Motion
- React Icons

## Development

Install dependencies:

```bash
npm install
```

Run the dev server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```

Lint the project:

```bash
npm run lint
```

## Project structure

- `src/App.tsx` — main portfolio page
- `src/main.tsx` — application entry point
- `src/index.css` — global styles
- `public/` — static assets such as images
